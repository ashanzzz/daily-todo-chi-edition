# Daily Todo

轻量、纯前端、离线优先的待办应用。

## 推荐运行方式

双击 `start-daily-todo.bat`。它会使用 Windows 自带 PowerShell 启动本地服务，并自动打开 `http://localhost:8080`。这个方式能提供更稳定的浏览器存储、PWA 离线缓存和更新行为；运行窗口保持打开时，本地服务会持续运行。

也可以直接双击 `index.html`，但文件模式下不同浏览器对本地存储的行为不完全一致，不推荐作为长期保存任务的方式。

## 数据安全

- 每次新增、编辑、完成、删除或更改设置，都会立即同步保存到 **IndexedDB**。
- 同时保留一个 localStorage 兼容副本：断电发生在 IndexedDB 写入完成前时，下一次启动会选择时间更新的副本恢复。
- 初次启动会自动迁移旧版 localStorage 任务到 IndexedDB，不会主动删除旧数据。
- 设置页显示当前保存状态、IndexedDB 使用状态与最近保存时间。
- 点击“立即备份”可下载版本化 JSON 文件；有任务且超过 30 天未备份时，会显示温和提醒。
- 清除浏览器“站点数据”、换浏览器或换设备仍会删除或隔离本地任务；请保留周期性 JSON 备份。

已在断电前被清空、且没有 JSON 备份的旧任务无法从浏览器中恢复。本次更新只能防止相同情形再次发生。

## 日历与历史

- 新增“日历”视图，可按月选择过去、今天或未来任意日期。
- 日期格会显示任务数量；紫点代表待完成，灰点代表已完成。
- 选中日期后，下方会同时列出待完成和已完成任务，方便回顾历史和安排未来。
- 左右按钮、月份选择器和“今天”按钮都可快速定位日期。

## 体验设计

- 移除了每次重新渲染时的页面淡入动画，避免点击任务、按钮或设置时出现整屏闪烁。
- 日历采用 44px 以上的主要触控目标、可见键盘焦点、明确的选中状态，以及深浅主题下的语义色彩。
- 在系统启用“减少动态效果”时，会进一步压低界面过渡。

## 源码管理

项目已初始化为 Git 仓库。Git 管理源码和配置，不管理浏览器中的任务数据。导出的 `daily-todo-backup-*.json` 已被 `.gitignore` 忽略，建议把个人备份保存到项目目录之外。

## 主要功能

- 今日任务、7 天日期切换、月日历、已完成视图
- 快速新增和完整任务编辑
- 时间、备注、重要标记与重复任务
- 完成 / 撤销、移到明天、搜索
- 浅色 / 深色主题
- IndexedDB 自动保存、JSON 导入和导出备份
- 桌面与手机响应式布局
