# Daily Todo Chi Edition

轻量、离线优先的待办应用。**任务数据库只保存到程序目录，不保存到浏览器缓存或浏览器数据库。**

## 必须使用启动器

双击 start-daily-todo.bat。它使用 Windows PowerShell 在本机启动数据服务，并自动打开 http://localhost:8080。

不要直接双击 index.html。浏览器出于安全限制，不能让 file:// 页面任意读写程序目录；本版本会阻止直接打开的页面加载或保存任务，以避免误以为数据已安全保存。

## 数据文件位置

运行启动器并做出第一次任务变更后，程序目录会生成：

- data/daily-todo-data.json：当前唯一的任务数据库，每次任务或设置变更后立即原子写入。
- data/backups/daily-todo-backup-YYYY-MM-DD.json：每日恢复快照。保留当天及之前 89 个日历日。

例如，本项目的数据文件会位于：

    D:\SynologyDrive团队\antigravity\daily-todo-standalone\data\daily-todo-data.json

浏览器缓存、Cookie、localStorage、IndexedDB 都不是任务数据源。因此清空浏览器缓存不会删除这个 data 文件夹中的任务。

## 保存与安全策略

- **活动保存**：每一次新增、编辑、完成、删除、导入或设置修改都会立即写入当前 JSON 数据库。
- **原子写入**：服务器先写入临时文件，再替换当前数据文件，降低断电时写出半个文件的风险。
- **并发保护**：数据文件有递增版本号。两个标签页同时更新时，后写的一方会收到冲突提示，而不会静默覆盖另一方的数据。
- **本地 API 安全**：数据接口仅监听 localhost / 127.0.0.1，并要求会话令牌、正确来源、JSON 内容类型和请求大小限制。
- **Git 隔离**：data/ 里的真实任务文件被 .gitignore 排除，不会提交或上传到 GitHub。
- **明文提醒**：JSON 文件是明文；Synology Drive 可以同步它，但可访问该同步目录的用户也能读取任务和备注。

## 恢复与迁移

- 设置页的“导出备份”会额外下载 JSON，适合异地或跨设备保存。
- 设置页的“导入数据”会将导出的 JSON 写入当前程序目录数据库。
- 如果你需要保留旧版本中仅存在于浏览器的任务，请先从旧版本导出 JSON，再在本版本导入。新版本不会继续从浏览器数据库读取任务。

## 主要功能

- 今日任务、步进式周历条、月日历和历史查看
- 快速新增、完整编辑、时间、备注、重要标记与重复任务
- 完成 / 撤销、移到明天、搜索
- 浅色 / 深色主题
- 程序目录 JSON 数据库、每日恢复快照和 JSON 导入 / 导出
- 桌面与手机响应式布局
