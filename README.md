# Daily Todo (Executive Edition / 迟总专用版)

轻量、优雅、离线优先的个人待办与日程规划应用。

> **核心设计理念**：**数据归属个人，坚决不丢数据。**

> 任务数据库**仅保存于本地程序目录**，不依赖任何第三方云端，也不依赖脆弱的浏览器缓存或浏览器数据库。清空浏览器缓存、Cookie、清理历史记录，**绝对不会丢失你的任务与数据**。

---

## 快速启动

### 方式一：Windows 用户（开箱即用，零依赖）
直接双击根目录下的：
```text
start-daily-todo.bat
```
系统将自动通过原生 Windows PowerShell 启动轻量数据服务，并在默认浏览器打开 `http://localhost:8080`。

### 方式二：macOS / Linux / 跨平台用户（Node.js）
在项目根目录下执行：
```bash
npm start
# 或
node server.js
```
服务启动后访问 `http://localhost:8080` 即可。

> **注意**：请勿直接通过 `file://` 双击 `index.html` 使用。现代浏览器安全沙箱会阻止本地网页读写本地磁盘文件，为防止用户误以为数据已落盘而丢失，系统会阻断未连接本地服务的写入。

## 数据存储与安全

所有的待办、备注、历史记录均透明可见，位于当前程序目录的 `data/` 文件夹下：

- **当前数据库**：`data/daily-todo-data.json`
  - 每次新增、修改、完成、删除任务，均**毫秒级即时原子落盘**。
  - 采用写临时文件后原子替换（Atomic Rename）机制，断电或崩溃不会写出半截损坏文件。
- **每日恢复快照**：`data/backups/daily-todo-backup-YYYY-MM-DD.json`
  - 每天第一次或多次操作会自动保留当天的独立备份快照。
  - 系统自动保留当天及之前 **90 个日历日**的历史快照，超出自动滚动清理。
- **Git 隔离与隐私**：`data/` 文件夹默认被 `.gitignore` 忽略，提交代码或推送到 GitHub 时**绝不会泄露任何个人任务或隐私内容**。
- **手动备份与迁移**：设置页提供随时可用的 JSON 导出与恢复功能，方便跨设备迁移。

## 主要特性

- **步进式周历条 (Stepper Week Strip)**：
  - 顶部 7 天周视图，支持点击 `‹` 与 `›` 快速翻至上一周 / 下一周。
  - 离开当前周时，智能显示高亮“回到今天”胶囊按钮，随时一键归位。
  - 每一天下方配有任务状态圆点（实心紫点代表有待办，空心圆环代表有已完成）。
  - 手机/触屏支持横向轻滑手势（Swipe）翻周。
- **整月日历与历史回顾**：
  - 可按月自由查看过去或未来的任意日期。
  - 点击历史日期可回顾当天已完成的工作；点击未来日期可快速排程。
- **优雅 UI/UX 设计**：
  - 遵循现代人机交互与无障碍规范，全键盘焦点可达。
  - 告别界面闪烁：移除全局淡入重绘动画，操作干脆流畅。
  - 浅色模式（Clean Warm Minimal）与深色模式（Dark Slate）一键切换。
- **并发与防冲突保护**：
  - 多标签页同时打开编辑时具备版本校验与冲突拦截，防止后写覆盖先写。
